# Encuesta Web Interactiva

Este proyecto consiste en una página web que permite a los usuarios realizar una encuesta. Los usuarios pueden proporcionar su nombre, edad, teléfono, correo electrónico y comentarios. Los resultados de la encuesta se muestran en la misma página después de que el usuario haya enviado el formulario.

## Funcionalidades

- **Formulario de encuesta**: Se activa cuando el usuario selecciona una casilla de verificación. Una vez activado, se muestra un formulario para ingresar los detalles.
- **Envío de la encuesta**: Al completar el formulario y hacer clic en "Enviar", los datos del usuario se muestran en la página y el formulario se oculta.
- **Visualización de resultados**: Después de enviar la encuesta, los resultados se muestran debajo del formulario.

## Estructura del Proyecto

El proyecto se compone de tres archivos principales:

1. **HTML (`index.html`)**: Contiene la estructura de la página, incluyendo el formulario de encuesta y la sección de resultados.
2. **CSS (`style.css`)**: Estilos para mejorar la apariencia visual de la página y los formularios.
3. **JavaScript (`main.js`)**: Lógica para mostrar/ocultar el formulario de encuesta y manejar el envío del formulario.

## Requisitos

Para correr este proyecto en tu entorno local, necesitas tener un servidor que sirva archivos estáticos. Puedes usar herramientas como:

- [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) en Visual Studio Code
- [http-server](https://www.npmjs.com/package/http-server) si tienes Node.js instalado
